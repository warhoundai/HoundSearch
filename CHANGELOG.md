# Changelog

## 0.1.0rc2

Polish the Python agent SDK: expose stable caller-supplied idempotency keys, explicit ingestion polling, and only supported HoundSearch endpoints. Adds a wire-contract regression test. No database or HTTP API migration.

## 0.1.0rc1

Initial self-hosted preview: tenant-local PostgreSQL full-text search, optional pinned local neural retrieval/reranking, explicit BYO search/model profiles, contents/similar/grounded answers, bounded resumable research, durable ingestion, REST/Python/JavaScript/MCP interfaces. Verification and limitations are documented separately; Exa parity is not claimed.
